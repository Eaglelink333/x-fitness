            Connect Apple Health

            Websites can't read Apple Health directly, so a free iPhone Shortcut reads your steps and active calories and sends them here. It takes about 5 minutes to set up once.

            1. Open the Shortcuts app → + (new shortcut). Name it Sync X-Fitness.
            2. Add Find Health Samples. Set Type: Steps, Start Date: is today.
            3. Add Calculate Statistics. Set it to Sum of Health Samples.
            4. Add Set Variable and name it steps.
            5. Repeat steps 2–4 with Type: Active Energy, and name the variable active.
            6. (Optional, if you use a smart scale) Add Find Health Samples with Type: Weight, Sort by Start Date, Latest First, Limit 1. Then add Set Variable and name it weight.
            7. Add URL with this text, inserting your variables where shown:
            8. Add Open URLs. Tap ▶ to test it. Safari will open and show "Synced from Apple Health".
            9. Automate it: in Shortcuts go to Automation → + → Time of Day (e.g. 8:00 pm, daily) → Run Immediately → choose Sync X-Fitness.

            The first time, iOS asks for permission to read Health data. Tap Allow. You also need to be signed in to X-Fitness in Safari once.
