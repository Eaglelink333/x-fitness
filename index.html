                  Connect Apple Health

                  Websites can't read Apple Health directly, so a free iPhone Shortcut reads your Health data and sends it to X-Fitness in the background. Nothing opens, and it works from automations. It takes about 5 minutes to set up once.

                  1. Open the Shortcuts app → + (new shortcut). Name it Sync X-Fitness.
                  2. Add Find Health Samples. Set Type: Steps, Start Date: is today. Set Group by: Day and turn on Fill Missing if it's offered, so days with no data send 0 instead of stopping the Shortcut.
                  3. Add Calculate Statistics. Set it to Sum of Health Samples.
                  4. Add Set Variable and name it steps.
                  5. Repeat steps 2–4 with Type: Active Energy → variable active.
                  6. (Apple Watch) Repeat steps 2–4 with Type: Exercise Minutes → variable exercise.
                  7. (Optional, smart scale) Find Health Samples, Type: Weight, Sort by Start Date, Latest First, Limit 1 → Set Variable weight.
                  8. Add Get Contents of URL. Tap the URL and paste:
                  9. Tap the › arrow on that action to show more. Set Method: POST.
                  10. Headers → Add new header. Key: Authorization. Value: paste
                  11. Request Body: JSON. Tap Add new field → Text for each of these:
                    • mode → type health
                    • key → paste your sync key (from the box above)
                    • steps → insert the steps variable
                    • active → insert the active variable
                    • exercise → insert the exercise variable
                    • weight → insert the weight variable (only if you did step 7)
                  12. (Optional) Add Show Notification with Contents of URL to see "Synced to X-Fitness: …".
                  13. Tap ▶ to test. Then open X-Fitness: your steps should be there.
                  14. Automate it: Automation → + → Time of Day → e.g. 12 pm, 5 pm and 8 pm, daily → Run Immediately (turn off Notify When Run) → Sync X-Fitness.

                  If you set up the older version (URL + Open URLs), delete those two actions and use steps 8–11 instead. The first time, iOS asks to read Health data: tap Allow.

                  Advanced: to sync workouts by name, a helper app like Toolbox Pro (Get Workouts) can build text lines of Name~Duration~Calories. Send them as a workouts field.

                  Daily reminders

                  A nudge each morning to weigh in, and one at night to finish logging. iPhone Shortcuts handles this with no extra setup on the server.

                  1. Open Shortcuts → Automation → + → Time of Day.
                  2. Pick 7:00 am, Daily, then Run Immediately.
                  3. Add the action Show Notification with the text Weigh in before breakfast, then log it in X-Fitness.
                  4. Repeat for 8:00 pm with Log today's food and check your net calories.

                  Tip: add the same notification to the end of your Sync X-Fitness Shortcut to see your synced numbers.
